# Rubrik Penilaian — Grammar & Penulisan Bahasa Inggris SMA

> Rubrik ini dirancang sebagai contoh acuan penilaian otomatis. Bobot dan kategori bisa disesuaikan dengan kebijakan guru atau sekolah masing-masing sebelum dipakai secara resmi.

## Tujuan Rubrik

Rubrik ini dipakai sistem sebagai acuan tetap ketika menilai jawaban siswa, supaya penilaian antar submission konsisten dan tidak berubah-ubah tergantung interpretasi AI di setiap percakapan.

## Kategori Penilaian

### 1. Ketepatan Grammar (Bobot: 40%)

| Skor | Kriteria |
|---|---|
| 4 (Sangat Baik) | Tidak ada kesalahan tata bahasa, atau maksimal 1 kesalahan minor yang tidak mengganggu makna |
| 3 (Baik) | Terdapat 2-3 kesalahan tata bahasa, makna kalimat masih dapat dipahami dengan jelas |
| 2 (Cukup) | Terdapat 4-6 kesalahan tata bahasa, sebagian makna kalimat menjadi ambigu |
| 1 (Kurang) | Lebih dari 6 kesalahan tata bahasa, makna kalimat sulit dipahami |

### 2. Ketepatan Kosakata (Bobot: 20%)

| Skor | Kriteria |
|---|---|
| 4 (Sangat Baik) | Pemilihan kata tepat dan bervariasi, sesuai konteks kalimat |
| 3 (Baik) | Pemilihan kata sebagian besar tepat, ada 1-2 kata kurang sesuai konteks |
| 2 (Cukup) | Beberapa kata dipilih kurang tepat, namun makna umum masih tersampaikan |
| 1 (Kurang) | Banyak pemilihan kata yang keliru sehingga mengubah makna kalimat |

### 3. Struktur dan Koherensi Kalimat (Bobot: 25%)

| Skor | Kriteria |
|---|---|
| 4 (Sangat Baik) | Kalimat tersusun logis dan runtut, transisi antar gagasan jelas |
| 3 (Baik) | Struktur kalimat cukup jelas, ada sedikit bagian yang kurang runtut |
| 2 (Cukup) | Struktur kalimat kadang membingungkan, urutan gagasan tidak selalu jelas |
| 1 (Kurang) | Struktur kalimat tidak jelas, sulit diikuti alur gagasannya |

### 4. Mekanik Penulisan (Ejaan & Tanda Baca) (Bobot: 15%)

| Skor | Kriteria |
|---|---|
| 4 (Sangat Baik) | Ejaan dan tanda baca hampir seluruhnya tepat |
| 3 (Baik) | Ada beberapa kesalahan ejaan/tanda baca kecil, tidak mengganggu pemahaman |
| 2 (Cukup) | Kesalahan ejaan/tanda baca cukup sering terjadi |
| 1 (Kurang) | Kesalahan ejaan/tanda baca sangat sering dan mengganggu pemahaman |

## Perhitungan Nilai Akhir

```
Nilai Akhir = (Skor Grammar x 0.40) + (Skor Kosakata x 0.20) 
            + (Skor Struktur x 0.25) + (Skor Mekanik x 0.15)

Nilai Akhir dikonversi ke skala 100:
Nilai 100 = (Nilai Akhir / 4) x 100
```

## Contoh Penerapan

Misal seorang siswa mendapat skor Grammar 3, Kosakata 3, Struktur 4, Mekanik 3:

```
Nilai Akhir = (3 x 0.40) + (3 x 0.20) + (4 x 0.25) + (3 x 0.15)
            = 1.2 + 0.6 + 1.0 + 0.45
            = 3.25

Nilai Skala 100 = (3.25 / 4) x 100 = 81.25 (dibulatkan menjadi 81)
```

## Panduan Pemberian Feedback

Setiap penilaian sebaiknya disertai feedback yang membangun, bukan sekadar angka. Struktur feedback yang disarankan:

1. **Apresiasi**: sebutkan satu hal yang sudah dilakukan dengan baik oleh siswa
2. **Area perbaikan**: sebutkan maksimal 2-3 kesalahan paling signifikan, disertai contoh perbaikannya
3. **Saran belajar**: sarankan topik grammar spesifik yang perlu dipelajari ulang, jika relevan
